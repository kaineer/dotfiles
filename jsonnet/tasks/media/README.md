# tasks/media/

Терминальные медиа-штуки (не GUI). Сборка: `main.jsonnet`.

| Файл | Что делает |
|---|---|
| `mocp.jsonnet` | конфиг/keymap/theme для mocp → `~/.moc/` |
| `cleanup-rmpc-mpd.jsonnet` | разово: остановить user mpd, убрать `~/bin/rmpc` и `~/.config/mpd` |

Новые медиа-утилиты — сюда (или в `desktop/`, если нужен GUI-хост).
